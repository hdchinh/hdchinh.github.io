Sparrow Wallet: Hướng dẫn nâng cấp và sao lưu an toàn

Hudson
Nov 2, 2026
· ~4 phút đọc
AWS & Security

Quy trình nâng cấp Sparrow Wallet trên macOS Apple Silicon, từ sao lưu cấu hình ví đến xác minh bộ cài và kiểm tra sau nâng cấp.

Ví dụ sử dụng ví multisig 2-of-2, Native SegWit (P2WSH) với hai hardware wallet Ledger và Trezor. Với cấu hình khác, đối chiếu wallet policy, script type và số cosigner theo ví đang sử dụng.

1. Backup trước khi nâng cấp

  1. Mở Sparrow → chọn ví cần sao lưu → Settings.
  2. Nhấn biểu tượng QR bên cạnh Descriptor → Save PDF... → lưu PDF với tên dễ nhận biết.
  3. Nhấn Export... ở góc dưới bên trái → chọn Output Descriptor → xuất file .txt.
  4. Kiểm tra descriptor có đầy đủ các cosigner, xpub, fingerprint, derivation path và nhánh receive/change.
  5. Thoát Sparrow (Cmd + Q), sao chép nguyên thư mục ~/.sparrow/wallets sang ổ lưu trữ riêng được mã hóa.
  6. Xác nhận recovery seed và passphrase (nếu có) của từng hardware wallet được cất giữ an toàn, ngoại tuyến.

2. Tải bộ cài chính thức

Website: https://sparrowwallet.com/download/

GitHub: https://github.com/sparrowwallet/sparrow/releases

Với Mac Apple Silicon, tải ba file cùng phiên bản:

  • Sparrow-X.Y.Z-aarch64.dmg
  • sparrow-X.Y.Z-manifest.txt
  • sparrow-X.Y.Z-manifest.txt.asc

3. Xác minh GPG và SHA-256

Mở Sparrow phiên bản cũ:

Tools → Verify Download

Điền:

  • Signature: File .asc
  • Manifest: File .txt
  • Release File: File .dmg
  • Public Key: Có thể bỏ trống nếu Sparrow đã nhận đúng khóa công khai.

Kết quả yêu cầu:

  1. Signed By: Craig Raw
  2. Release Hash: Matched manifest hash
  3. Verified: Ready to install

Fingerprint tham chiếu của khóa ký Craig Raw dưới đây cần được đối chiếu với hướng dẫn xác minh chính thức, không chỉ dựa vào tên người ký:

Đối chiếu kết quả với dòng tương ứng của file DMG trong manifest đã xác minh chữ ký. Hash phải đúng cả phiên bản lẫn kiến trúc bộ cài; không dùng lại hash của phiên bản cũ.

4. Cài đặt / nâng cấp

  1. Thoát Sparrow bằng Cmd + Q.
  2. Mở file DMG đã xác minh.
  3. Kéo Sparrow vào Applications.
  4. Chọn Replace để thay ứng dụng cũ.
  5. Mở Sparrow mới và xác nhận số phiên bản.

Không cần nhập seed, kết nối hardware wallet hay chuyển BTC trong lúc cài đặt.

5. Kiểm tra sau nâng cấp

Mở lại ví đã sao lưu và đối chiếu với cấu hình trước nâng cấp:

  1. Số dư và lịch sử giao dịch hiển thị đúng.
  2. Wallet policy không thay đổi, chẳng hạn 2-of-2 trong ví dụ này.
  3. Script type không thay đổi, chẳng hạn Native SegWit (P2WSH).
  4. Danh sách cosigner và cấu hình keystore không thay đổi.
  5. Địa chỉ nhận BTC tại cùng nhánh và chỉ số khớp với địa chỉ đã xác minh trước đó.
  6. Sparrow kết nối server và đồng bộ bình thường.

Nếu có bất thường, dừng thao tác và kiểm tra trước khi ký giao dịch.

6. Nguyên tắc bảo mật

  • Không nhập recovery seed Ledger/Trezor vào máy tính hoặc website.
  • Không chỉnh sửa descriptor hay xpub trong quá trình nâng cấp.
  • Không chia sẻ công khai descriptor hoặc xpub vì có thể lộ thông tin giao dịch.
  • Nếu cài mới hoàn toàn, cần xác minh chữ ký GPG bằng công cụ độc lập trước khi cài, rồi khôi phục từ backup ví hoặc descriptor.
  • Với multisig 2-of-2, cần cả hai signer hợp lệ để chi tiêu BTC.

Quy tắc: Backup → Verify Signature → Verify Hash → Install → Verify Wallet.
