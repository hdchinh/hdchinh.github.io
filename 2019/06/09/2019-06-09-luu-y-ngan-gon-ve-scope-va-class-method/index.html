Khi nào dùng?

  • Query ngắn, declarative, tái sử dụng → scope.
  • Logic nhiều nhánh/tham số → class method.
  • Domain query lớn → query object.

Không đặt query evaluation như .to_a, .first vào giữa chain nếu muốn tiếp tục compose.

default_scope

Cẩn thận với default_scope; nó tác động ngầm lên mọi query và update. Multi-tenancy/security không nên chỉ dựa vào một default scope dễ unscoped.

Scope không tốt hơn class method vì ngắn hơn. Giá trị thật là trả relation có contract rõ. DSL đẹp nhưng trả dữ liệu bất ngờ vẫn chỉ là bug mặc vest.
