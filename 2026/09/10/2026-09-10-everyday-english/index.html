Everyday English

Hudson
Sep 10

Nơi tôi ghi lại những câu tiếng Anh thường dùng hằng ngày để có thể quay lại và dùng khi cần.

Bài viết này sẽ được cập nhật liên tục.

1. Daily report

1.1. Nothing to report

  • I have no major updates today. I’m working on module 4 user journey, with no blockers at the moment.

1.2. Confirm the expected timeline

  • I should have it ready for QA by the end of this week.
  • I should have it ready for QA in the next two days.

1.3. Waiting for something

  • I’m currently waiting for confirmation from Sirrish before I can continue with these tickets.
  • I’ve reached out to Vlad to review the architecture. Once he’s done, I’ll pick up the production setup immediately.
  • I’m waiting for a response from Vlad on the architecture review. I just wanted to mention it in case anyone can help move it forward.

1.4. Request a meeting or sync with someone

  • I’d like to have a meeting with Anida after the daily call, if that works for you. Otherwise, please suggest a time when we can meet.
  • Anida, can we sync after this call? If that doesn’t work, just let me know a time that’s good for you.
  • I’d like to have a quick sync with Anida after the daily call, if that works for you, Anida. If not, feel free to suggest a time.

1.5. Finished one task, moving on to the next

  • I’m done with the authentication module. I’ll pick up the payment integration today.
  • I’ll be done with the authentication module by the end of this week. Starting next week, I’ll pick up the test automation work. Please let me know if there are other tasks you’d like me to take instead.

1.6. Task delayed by unexpected work

  • I had to work on a login issue yesterday. It came in at the last minute from Sirrish, so I’ll be continuing the payment integration today. I should have it ready for QA by Thursday, one day later than originally planned. Are you okay with that?

1.7. Confirm that something is feasible

  • This is something we can do.

1.8. Flag something the other person should be aware of

  • I want to bring up a couple of things before we go ahead

1.9. Explain required work and dependencies

  • On my end, I’ll need to spend some time updating the admin panel and the API to support this. Once that’s ready, Om will also need to do some work on his side to integrate with the API I provide.

1.10. Point out the drawbacks

  • One thing I should point out: this is probably the quickest path forward, but it is not the most optimal setup. The reason is Querylah’s content would end up living inside the Sirrista database, which is not ideal in the long run.

1.11. Ask a partner or manager for confirmation

  • If you want to go with this, I can investigate the scope and create tasks for both the admin panel and the API work. Just let me know if this is what you want to do.

1.12. Clarify who is responsible for a task

  • If we go with a separate setup, this would actually be something Om needs to handle. He would need to develop a simple admin panel to handle the blog’s content management flow, so he’s the only one who can give you a rough estimate in this case.

1.13. Confirm ownership while requesting time for an accurate estimate

  • If we go with the existing Sirrista API route, this is something I can take care of. I would need some time to look into it properly before I can give you an accurate estimate. My guess right now is around two days, but this is not a confirmed number yet.

2. Talking to AI

2.1. Ask it to confirm its understanding first

  • Can you confirm your understanding before moving forward? No changes are needed for now.

2.2. Ask it to investigate and provide an estimate

  • Can you investigate this and get back to me with an estimate? No changes are needed for now.

2.3. Ask AI to compare screenshots when one displays incorrectly

  • Can you check these screenshots? One displays correctly, while the other doesn’t. The only difference is that one was opened in a regular Chrome tab and the other in an incognito Chrome tab.

2.4. Ask why something is happening now but did not happen before

  • Why is this only happening now and not before? Did something change recently?
