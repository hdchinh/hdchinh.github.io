require, load, include, prepend và extend trong Ruby

Hudson
May 15
ruby notes
ruby

Các method này đều “đưa code vào đâu đó”, nhưng ở các tầng hoàn toàn khác nhau.

require

Load feature một lần và ghi vào $LOADED_FEATURES. Dùng cho standard library/gem. Return true khi load mới, false khi đã load.

require_relative

Resolve path tương đối với file hiện tại, phù hợp code project không có load path setup.

load

Thực thi file mỗi lần gọi. Hữu ích cho script/reloading đặc biệt, không phải import mặc định. load(path, true) wrap trong anonymous module để giảm constant pollution.

include

Đưa module vào ancestor chain cho instance method.

prepend

Module đứng trước class trong lookup chain, phù hợp wrap method bằng super.

extend

Include module vào singleton class của object; với class object, methods trở thành class methods.

Mental model

  • require/load: thực thi file.
  • include/prepend/extend: thay đổi method lookup.

Chúng không thay thế nhau. require file định nghĩa module không tự include module đó; Ruby load code nhưng không đoán kiến trúc hộ ta. May mắn thay, vì codebase đã đủ bất ngờ rồi.
